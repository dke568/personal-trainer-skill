# Проверка версии

Проверено 21 ноября 2026 (Europe/Moscow), Python 3.12, Linux.

- 37 автоматических проверок: расчёты, происхождение данных, недельный объём,
  запись/исправление журнала, блокировки, Unicode, защита приватного указателя.
- Формат личного навыка прошёл штатный валидатор.
- Исходный журнал: 14 валидных записей; неизвестные даты не уточнялись искусственно.
- Реестр: 30 уникальных источников с обязательными метаданными.
  Это проверка структуры и идентификаторов, не независимая оценка научной истины.
- Независимая проба на вопросах о последних весах, объёме груди и калориях.
- Исправлены найденные ошибки обработки Unicode, исправлений синтетических
  данных, зависших блокировок и путей через символические ссылки.
- Проверка git diff --check пройдена.

Исходная версия прошла GitHub Actions на Linux, Windows и macOS.
После расширения научных/образовательных справочников локальные проверки
снова пройдены; результат нового удалённого запуска проверяется после публикации.
Windows/macOS локально не проверялись. Надёжность сетевых файловых систем,
отказ диска и аварийное отключение питания этой проверкой не установлены.
Научная база — 30 отобранных источников с проверенной библиографией/аннотациями,
7 разборов указанных разделов полных текстов и 2 дополнительных письма по белку.
Три открытых плана подготовки тренеров учтены отдельно; доступ к платным
курсам и сертификация не заявляются. Полный систематический обзор не проведён.

Дополнительная независимая проба расширения: сертификация, длина мышцы,
неприменимые сетевые ранги и белковая переписка — ожидаемые разграничения
сохранены, ограничения доступа названы. Учебный пример не записан как тренировка.
