# Science-based coach repository

For coaching, read science-based-coach/SKILL.md and the relevant references.
Read coach-data/INDEX.md and the athlete's latest state before recommendations.
Respect evidence access limits, uncertainty and the separation of plans/completed work.

For engineering, preserve provenance and append-only history. Run the standard-library
tests and source audit after relevant changes. Do not turn unknown dates into facts,
examples into actual sessions, or offline structure checks into scientific validation.
Never commit private clinical state, credentials or references/user-context.json.
