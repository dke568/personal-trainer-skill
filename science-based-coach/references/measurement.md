# Измерения и сравнение

Разделить наблюдаемый показатель и вывод о ткани. Весы измеряют массу,
лента — окружность, УЗИ — локальную толщину; ни один показатель не даёт
безошибочной полной картины. Безжировая масса содержит воду и другие ткани.
CREATINE-HYPERTROPHY-2023 показывает важность различия исходов.

Для личного контроля сохранять точку измерения, позу, напряжение,
время/условия и приблизительность. Массу сравнивать серией сопоставимых
измерений; не требовать ежедневного взвешивания против желания.
Не трактовать единичный сантиметр при разных условиях как установленный жир.
Не выводить точный процент жира из фото или форму мышцы из одного ракурса.

Окружность плеч не равна линейной ширине. Живот у пупка не равен бёдрам.
Не менять дату старого значения при обновлении дневника.
Новое значение — новое событие; исправление старого — supersedes.
