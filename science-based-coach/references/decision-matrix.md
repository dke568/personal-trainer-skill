# От доказательства к решению

Уверенность ниже — рабочая оценка, не самостоятельно проведённый GRADE.
Не ранжируй работы только по году. Не складывай перекрывающиеся обзоры как
независимые репликации. Источники и глубина доступа — в sources.json.

| Вопрос | Рабочая оценка | Решение и граница |
|---|---|---|
| Доза, нагрузка, частота | Умеренная для общих тенденций; низкая для личного точного оптимума | ACSM-2026, VOL-2026, RX-2023: учитывать всю неделю; распределять и калибровать, не назначать по лучшему рангу |
| Нужно ли доводить всё до отказа | Умеренная против обязательности; точный лучший запас не установлен | FAILURE-2023 и RIR-2024: отделять определения и фактическую дистанцию; не считать метарегрессию причинным доказательством |
| Длинная мышца и амплитуда | Низкая/умеренная, зависит от мышцы и сравнения | LENGTH-2026, LENGTH-META-2025, ROM-2023: сохранять противоречия; удобная воспроизводимая амплитуда; не тянуть через симптомы |
| Периодизация | Умеренная для некоторых силовых задач; преимущество роста неясно | PERIOD-2022: планировать нагрузку без обязательной сложной схемы |
| Порядок | Умеренная для специфической силы, слабее для роста | ORDER-2021: приоритетное движение раньше, если это помогает задаче |
| Кардио | Умеренная для исследованных доз; не для экстремальных объёмов | CONCURRENT-2022: не запрещать кардио; учитывать ноги, питание и взрывную силу |
| Белок | Умеренная для небольшого среднего дополнительного эффекта при силовых | PROTEIN-2018/2022: адекватность важнее бесконечного увеличения; безжировая масса не равна чистым мышцам |
| Сложные методы | Низкая/умеренная, мало данных на очень опытных | ADVANCED-2026: не обязательны; не переносить ранги других исходов на рост |

## При конфликте
1. Сверь, действительно ли изучены одинаковые люди, движения и исходы.
2. Сравни отбор, определения, риск ошибок, интервалы и дозу.
3. Назови, что остаётся неизвестным и изменит ли это сегодняшнее решение.
4. Выбери небольшую обратимую пробу с измеримым результатом.
Не добавляй объём, новые методы или покупки лишь потому, что есть новая публикация.
