# Научный тренер: силовые, гипертрофия и дневник

Персональный тренер-аналитик для долгой работы с одним атлетом: проверяемая
история, научные источники, постепенная корректировка действующей программы.

Этот форк перерабатывает [npapatheodorou/personal-trainer-skill](https://github.com/npapatheodorou/personal-trainer-skill).
Архитектурные идеи других проектов и условия использования описаны в [ATTRIBUTION.md](ATTRIBUTION.md).

## Концепт

1. **Сначала факты.** Профиль, программа, выполненные подходы и их источники.
2. **Наука с ограничениями.** У каждого вывода — проверяемый источник и применимость.
3. **Небольшие проверяемые изменения.** Наблюдение → гипотеза → корректировка → пересмотр.
4. **Полная недельная картина.** Прямые и косвенные подходы, соседние дни и восстановление.
5. **Честная память.** Планы не превращаются в результаты; неизвестные даты остаются неизвестными.
6. **Удовольствие от тренировок.** Предпочтения атлета учитываются наряду с эффективностью.

Основная инструкция: [science-based-coach/SKILL.md](science-based-coach/SKILL.md).
Для агента в этом репозитории точка входа — [AGENTS.md](AGENTS.md).

### Действующая основа и последняя проба

Сплит: четверг — спина/бицепс/дельты/предплечья; суббота — ноги;
воскресенье — грудь/дельты/трицепс. Последнее предложение: добавить умеренный
жим в четверг и попробовать 80 кг как основной вес в воскресенье.
**Три подхода с 80 кг ещё не выполнены по имеющимся данным.**
Разгрузка конца октября не означает, что текущая неделя тоже разгрузочная.

Полного свежего журнала вспомогательных подходов нет. Известные подходы —
нижняя граница доступного отчёта, не полная программа и не полный недельный объём.

## Расчёты и проверки

Python 3.10+, без сторонних пакетов. Команды из корня репозитория:

~~~bash
python science-based-coach/scripts/coach_tools.py --help
python science-based-coach/scripts/coach_tools.py macros --protein 200 --carbs 100 --fat 50
python science-based-coach/scripts/coach_tools.py validate --log coach-data/danya/events.jsonl
python science-based-coach/scripts/coach_tools.py weekly-volume --log coach-data/danya/events.jsonl --start 2026-11-01 --end 2026-11-20
python science-based-coach/scripts/coach_tools.py audit-sources --registry science-based-coach/references/sources.json
python -m unittest discover -s tests -v
~~~

Оценка 1ПМ — расчёт, не измеренный максимум. Недельный счётчик использует
только подтверждённые сессии с точной датой. Ноль датированных подходов
при пустом покрытии **не означает**, что человек не тренировался.
Флаг полноты периода разрешён только после явного подтверждения покрытия.

Исправления добавляются с supersedes, прошлые байты сохраняются.
Блокировки защищают локальных писателей; JSONL не заменяет транзакционную
базу данных или надёжное удалённое хранилище. Повреждённый журнал отклоняется
без автоматического удаления записей.
